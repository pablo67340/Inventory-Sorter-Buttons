|==============================================================|
| INVENTORY SORTER BUTTONS - a tribute to Inventory Tweaks     |
| Shortcuts reference                                          |
|==============================================================|

# This recreation's shortcuts are fixed to the original defaults:
#
#   Sort inventory ..................... R (rebindable in Options > Controls)
#   Sort a chest ....................... Middle click, or the z / || / = buttons
#   Drop the whole stack ............... Alt + Click
#   Move one item across ............... Ctrl + Click
#   Move all stacks of that item ....... Ctrl + Shift + Click
#   Move everything in that section .... Space + Click
#
# The individual shortcut toggles live in the in-game settings screen
# (the "..." button on any chest), and the sort key can be rebound in
# the vanilla Controls menu. Custom key mappings per shortcut are not
# part of this recreation.
